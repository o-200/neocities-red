# Security Policy

We **do not** support security updates in public API's on neocities. If you're discovered a security vulnerability, please contact to neocities's creator via [this form](https://neocities.org/contact) to fix public API.

If you discover a security vulnerability which doesn't related to API, open a public issue with your contacts and i will contact to you.

Thank you for helping keep this project and its users safe! 💙
